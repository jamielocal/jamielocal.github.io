PowerTrims

By _divi._

More Info

PowerTrims is a Lightweight mod to Add Trim Effects, to each and every Trim!

Some Are:

  • Wild Trim | You get a Fun, and Unique, Balanced Grapple effect!
  • Slience Trim | You get Strength 3 for as long as you have that set on
  • And Much More! | We are Working on New Features on the Daily!

Message me For Any more Questions!

Features

  • Super Lightweight And Fast
  • Supports, Bukkit, Spigot, and Paper!
  • Tons of Trim Effects, and working on tons more to add!
  • Works on Any Server Version 1.21+
  • Crossplay Support
